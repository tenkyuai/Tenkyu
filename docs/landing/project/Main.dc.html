How many of your free credits went to farmers?

Run python -m tenkyu audit signups.csv on your own signup export and find out, offline, in one command. Then let the same small Python library score new signups as allow, review or block, with the reasons. No dependencies, no network calls.

Ten lines to your first decision

Create one Guard for the life of your process and call check on every signup. The second call is the same person using a new alias, and it comes back as a block.

Install it from PyPI with pip install tenkyu. Python 3.11 or newer, no dependencies.

from tenkyu import Guard, Signup

guard = Guard()  # in-memory; reuse one Guard for the life of your process
UA = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_7) Chrome/120.0 Safari/537.36"

first = guard.check(Signup(email="john@gmail.com", ip="203.0.113.7", device_id="dev-1", user_agent=UA))
print(first.action, first.reasons)  # allow []

# Same person, new alias, hoping for another batch of free credits:
again = guard.check(Signup(email="j.o.h.n+free2@gmail.com", ip="203.0.113.7", device_id="dev-1", user_agent=UA))
print(again.action, again.reasons)  # block ['this email (or an alias of it) already signed up']

if again.action != "allow":
    print("withhold free credits; send to manual review" if again.action == "review" else "reject signup")

It works on lazy farming and misses determined farming

These numbers come from a synthetic data set we generated ourselves. They compare Tenkyu with naive rules on behaviors we imagined. They are not a measurement of real-world accuracy.

The set has 2,000 real users and 200 farmers who open 863 extra accounts across five strategies in one simulated week. Flagged means review or block. Reproduce it with PYTHONPATH=src python benchmarks/farming_bench.py.

Residential farmers use a fresh home IP, a fresh device and an unrelated Gmail address for every account. Tenkyu catches none of them.

None of the 2,000 real users were blocked. The 75 (3.7%) who were flagged all went to review, and every one shared a device id with other accounts, which in this data is a household computer. A shared device alone never reaches block, so a farmer who only reuses one device gets review and a quarter of the free credits. Shared office IPs triggered nothing.
