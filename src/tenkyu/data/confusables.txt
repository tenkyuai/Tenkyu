# Subset rules: one source code point per line; the skeleton is 1-3 lowercase ASCII letters or digits; the source

# Armenian, Latin-extended/IPA or fullwidth character that NFKC + accent stripping would not already
# turn into the same ASCII. Math alphanumerics (U+1D400..) and letterlike symbols (U+2100.., e.g. the script l U+2113) are handled by NFKC in code
# and are not listed.
# Digit and letter swaps used in phishing (0 -> o, 1 -> l, rn -> m, vv -> w, cl -> d) are skeleton rules in
# lookalike.py, not data lines. Do not add punctuation or separator look-alikes: they would change label structure.
# Format: <code point hex> <ascii skeleton>   (text after # is ignored)
